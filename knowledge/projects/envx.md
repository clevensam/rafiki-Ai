# EnvX — Environment Variable Management Platform

## Project
Centralized platform to organize and secure environment variables while improving deployment
consistency across development teams. Built at Mbeya University of Science and Technology (MUST),
Mbeya, Tanzania (2026).

## Situation (Problem)
Developers working across multiple projects experienced repeated deployment failures and
inconsistent application behavior due to poorly managed environment variables and unstructured
configuration files.

## Task
Build a centralized platform to organize and secure environment variables while improving
deployment consistency across development teams.

## Action (Solution)
- Designed workflows for managing .env configurations and structured, project-based environment organization.
- Simplified team collaboration through standardized configuration processes.
- Built with Node.js-style backend workflows, environment variables (.env), deployment
  configuration, and Docker-like development environments, aligning with scalable system setup and
  DevOps-oriented practices.
- Repository: https://github.com/clevensam/envx-cli

## Result (Impact)
- Reduced configuration-related deployment issues by approximately 60%.
- Improved setup speed for new development environments by 50%.
- Minimized time spent troubleshooting environment conflicts from several hours to less than
  30 minutes per deployment cycle.

## Talking Points for Interviews
- "I reduced environment-related deployment failures by ~60% by centralizing and standardizing how teams manage .env files."
- "I built DevOps-oriented tooling with Node.js and Docker-like workflows."
- Emphasize operational reliability, configuration management, and developer productivity.
