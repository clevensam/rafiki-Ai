# Church Financial Management System

## Project
A financial management system to improve organization, financial transparency, and reporting
efficiency for Majengo Parish, Kilimanjaro, Tanzania (2025-2026).

## Situation (Problem)
Majengo Parish managed financial records manually, resulting in time-consuming bookkeeping processes,
unorganized contribution records, and difficulties generating accurate financial reports.

## Task
Build a financial management system to improve organization, financial transparency, and reporting
efficiency within the parish.

## Action (Solution)
- Developed modules for contribution tracking, transaction management, financial reporting, and
  organized digital record storage.
- Designed workflows that simplified record management and improved accessibility of financial data.
- Gained experience in structured backend development, financial transaction processing, reporting
  systems, and relational database management — supporting skills needed for enterprise backend
  systems like Java/Spring Boot and Postgres-based applications.

## Result (Impact)
- Reduced financial report preparation time from multiple days to a minute.
- Improved record organization efficiency by approximately 75%.
- Streamlined financial tracking processes for faster, more accurate reporting.
